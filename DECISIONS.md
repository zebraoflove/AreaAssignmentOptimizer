# DECISIONS

## Принятые решения

- SQLite является единственным источником истины.
- CSV используются только для импорта и экспорта.
- Архитектура проекта считается зафиксированной.
- Все территориальные изменения описываются через таблицу territory_adjustments.
- Каждый квадратный километр учитывается ровно один раз.
