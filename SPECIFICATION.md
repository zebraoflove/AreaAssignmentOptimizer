# SPECIFICATION

## Цель

Для каждого субъекта РФ подобрать уникальную комбинацию из 1–3 стран, сумма площадей которых максимально близка к площади субъекта, но не превышает её.

## Ограничения

- каждая страна используется только один раз;
- максимум три страны;
- превышение площади запрещено.

## Критерии оптимальности

1. Минимизировать максимальный остаток.
2. Минимизировать сумму остатков.
3. Минимизировать число используемых стран.
