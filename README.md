# AreaAssignmentOptimizer

## Описание

AreaAssignmentOptimizer — исследовательская система для сопоставления субъектов Российской Федерации с уникальными комбинациями государств-кандидатов на основе площади.  
Цель проекта — исследовать алгоритмы, позволяющие минимизировать расхождение между площадью субъекта РФ и площадью назначенной ему комбинации.

## Текущий этап

Базовый pipeline реализован:

```
исходные данные
    ↓
импорт и подготовка
    ↓
нормализация территориальных данных
    ↓
candidate sets
    ↓
Greedy
    ↓
оценка результата
    ↓
экспериментальный отчёт
```

Нормализация списка государств и территорий завершена.  
 Определены правила территориальных корректировок, обработки спорных территорий, ручных добавлений и формирования итоговых площадей.

Текущий этап проекта — выделение специализированных этапов нормализации данных в независимые модули и реорганизация `import_adjustments.py` в координатор pipeline.

После завершения архитектурного разделения планируется повторная оценка базового алгоритма `Greedy` на окончательном наборе нормализованных данных.

Проект находится в активной разработке.
