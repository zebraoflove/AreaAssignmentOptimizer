# AreaAssignmentOptimizer

## Описание

AreaAssignmentOptimizer — исследовательская система для сопоставления субъектов Российской Федерации с уникальными комбинациями государств-кандидатов на основе площади.

Цель проекта — исследовать алгоритмы, позволяющие минимизировать расхождение между площадью субъекта РФ и площадью назначенной ему комбинации.

## Текущий этап

Базовый pipeline реализован:

```text
исходные данные
    ↓
импорт и подготовка
    ↓
нормализация территориальных данных
    ↓
candidate sets
    ↓
Greedy
    ↓
оценка результата
    ↓
экспериментальный отчёт
```

Нормализация списка государств и территорий завершена.

Определены правила территориальных корректировок, обработки спорных территорий, ручных добавлений и формирования итоговых площадей.

Реализовано ручное добавление отсутствующих государств и субъектов/территорий, после чего они участвуют в последующих этапах pipeline.

Актуальный набор данных включает:

- 248 государств и территорий после подготовки;
- 89 субъектов РФ;
- 89 candidate sets;
- 7798 элементов candidate sets;
- 89 итоговых назначений Greedy.

Базовый алгоритм `Greedy` проверен на актуальном наборе данных в трёх вариантах порядка обработки субъектов:

- `original`;
- `ascending`;
- `descending`.

Все три варианта формируют полное допустимое распределение из 89 назначений без нарушения установленных ограничений.

На текущем наборе данных суммарная абсолютная ошибка для всех трёх вариантов составляет 655090 км², при этом распределение ошибок между отдельными субъектами различается.

Текущий этап проекта — анализ слабых мест `Greedy` и подготовка следующего алгоритма сопоставления.

## Проектный статус

Проект находится в активной исследовательской разработке.

Базовая инфраструктура, импорт данных, нормализация, генерация candidate sets, baseline-алгоритм Greedy и инфраструктура экспериментов реализованы.

Следующая задача — определить ограничения текущего Greedy и разработать алгоритм, способный улучшить качество распределения при сохранении всех установленных ограничений.
