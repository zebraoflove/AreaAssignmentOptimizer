# AreaAssignmentOptimizer

## Описание

AreaAssignmentOptimizer — исследовательская система для сопоставления субъектов Российской Федерации с уникальными комбинациями государств-кандидатов на основе площади.

Цель проекта — исследовать алгоритмы, позволяющие минимизировать расхождение между площадью субъекта РФ и площадью назначенной ему комбинации.

## Текущий этап

Базовый pipeline реализован:

```text
исходные данные
    ↓
импорт и подготовка
    ↓
candidate sets
    ↓
Greedy
    ↓
оценка результата
    ↓
экспериментальный отчёт

```

Текущий этап проекта — нормализация списка государств и территорий перед повторной оценкой базового алгоритма.

Проект находится в активной разработке.
