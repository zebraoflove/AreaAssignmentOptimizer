# AreaAssignmentOptimizer

## Описание

Универсальная система оптимизации для сопоставления уникальных комбинаций стран с целевыми регионами по площади с минимальным остатком.

Текущая задача проекта — оптимальное сопоставление субъектов Российской Федерации с комбинациями стран мира на основе площади территории.

## Основные возможности

- SQLite как единый источник данных
- Импорт и валидация данных
- Автоматическое построение итоговой модели территорий
- Генерация допустимых комбинаций стран
- Оптимальное распределение комбинаций между субъектами
- Экспорт результатов в Excel и CSV
