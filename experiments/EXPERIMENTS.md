# EXPERIMENTS

Журнал проведённых экспериментов и их результатов.

---

## 1. Greedy — без ограничения площади

**Constraint:** отсутствует


| Subject order | Average relative error |
| ------------- | ---------------------- |
| `original`    | **3.37%**              |
| `ascending`   | 4.14%                  |
| `descending`  | 4.16%                  |


### Observations

- `original` показал наименьшую среднюю относительную ошибку.
- `ascending` и `descending` дали близкие результаты.
- Ограничение `country area <= subject area` не применялось.

### Conclusion

При отсутствии ограничения на превышение площади порядок `original` показал наилучшую среднюю относительную ошибку среди проверенных вариантов.

---

## 2. Greedy — с ограничением площади

**Constraint:** `country area <= subject area`

Для всех трёх вариантов:

- Assignments: 85
- Unique subjects: 85
- Unique countries: 85
- Constraint violations: 0
- Total absolute error: 623741 км²


| Subject order | Average absolute error | Median absolute error | Maximum absolute error | Average relative error | Median relative error | Maximum relative error |
| ------------- | ---------------------- | --------------------- | ---------------------- | ---------------------- | --------------------- | ---------------------- |
| `original`    | 7338.1 км²             | 2600 км²              | 68410 км²              | 6.76%                  | 3.03%                 | 37.90%                 |
| `ascending`   | 7338.1 км²             | **2260 км²**          | 69130 км²              | **6.56%**              | **2.41%**             | 49.77%                 |
| `descending`  | 7338.1 км²             | 3660 км²              | **43000 км²**          | 7.02%                  | 6.26%                 | **23.46%**             |


### Observations

- `ascending` показывает наименьшие среднюю и медианную относительные ошибки.
- `descending` показывает наименьшие максимальные абсолютную и относительную ошибки.
- `original` занимает промежуточное положение по большинству показателей.
- Все три порядка дают одинаковую сумму абсолютных ошибок: 623741 км².
- Порядок обработки субъектов изменяет распределение ошибок между назначениями, но не изменяет их суммарную абсолютную величину.
- Во всех трёх вариантах сформировано полное допустимое распределение без нарушений ограничений.

### Conclusion

Порядок обработки субъектов влияет на распределение ошибок и отдельные показатели качества Greedy.

На текущем наборе данных:

- `ascending` имеет лучшее типичное качество;
- `descending` лучше контролирует наиболее плохие случаи;
- `original` может использоваться как нейтральная контрольная конфигурация.
