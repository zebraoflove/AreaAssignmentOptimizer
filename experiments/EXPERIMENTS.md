| ------------- | ---------------------- |

| `ascending`   | 4.14%                  |

### Observations

- `original` показал наименьшую среднюю относительную ошибку.

## 2. Greedy — с ограничением площади, старый набор

**Constraint:** `country area <= subject area`

Исходный эксперимент проводился на **85 субъектах**.


| Subject order | Assignments | Unique subjects | Unique countries | Total absolute error | Average absolute error | Median absolute error | Maximum absolute error | Average relative error | Median relative error | Maximum relative error |
| ------------- | ----------- | --------------- | ---------------- | -------------------- | ---------------------- | --------------------- | ---------------------- | ---------------------- | --------------------- | ---------------------- |
| `original`    | 85          | 85              | 85               | 625091 км²           | 7338.1 км²             | 2600 км²              | 68410 км²              | 6.76%                  | 3.03%                 | 37.90%                 |
| `ascending`   | 85          | 85              | 85               | 625091 км²           | 7338.1 км²             | **2260 км²**          | 69130 км²              | **6.56%**              | **2.41%**             | 49.77%                 |
| `descending`  | 85          | 85              | 85               | 625091 км²           | 7338.1 км²             | 3660 км²              | **43000 км²**          | 7.02%                  | 6.26%                 | **23.46%**             |


### Historical data correction

В первоначальной записи этого эксперимента было указано:

`Total absolute error: 623741 км²`

Фактический Excel-отчёт для старого набора содержит **625091 км²**. Средняя абсолютная ошибка `7338.1 км²` также соответствует 625091 / 85.

Поэтому **625091 км²** считается корректным значением старого baseline.

### Observations

- `ascending` показывает наименьшие среднюю и медианную относительные ошибки.
- `descending` показывает наименьшие максимальные абсолютную и относительную ошибки.
- `original` занимает промежуточное положение по большинству показателей.
- Все три порядка дают одинаковую сумму абсолютных ошибок.
- Порядок обработки субъектов изменяет распределение ошибок между назначениями, но не изменяет их суммарную абсолютную величину.
- Во всех трёх вариантах сформировано полное допустимое распределение без нарушений ограничений.

## 7. Сравнение старого и нового baseline

Старый baseline содержит 85 субъектов, новый — 89.

### Средняя абсолютная ошибка

```
85 субъектов: 7338.1 км²
89 субъектов: 7360.6 км²

Изменение: +22.5 км² на субъект
```

Средняя абсолютная ошибка изменилась незначительно.

### Относительная ошибка


| Subject order | Старый набор | Новый набор | Изменение  |
| ------------- | ------------ | ----------- | ---------- |
| `original`    | 6.76%        | 8.34%       | +1.58 п.п. |
| `ascending`   | 6.56%        | **7.99%**   | +1.43 п.п. |
| `descending`  | 7.02%        | 8.81%       | +1.79 п.п. |


### Медианная относительная ошибка


| Subject order | Старый набор | Новый набор | Изменение  |
| ------------- | ------------ | ----------- | ---------- |
| `original`    | 3.03%        | 4.17%       | +1.14 п.п. |
| `ascending`   | **2.41%**    | **2.41%**   | 0 п.п.     |
| `descending`  | 6.26%        | 6.79%       | +0.53 п.п. |


### Максимальная относительная ошибка


| Subject order | Старый набор | Новый набор | Изменение   |
| ------------- | ------------ | ----------- | ----------- |
| `original`    | 37.90%       | 52.15%      | +14.25 п.п. |
| `ascending`   | 49.77%       | 68.74%      | +18.97 п.п. |
| `descending`  | **23.46%**   | **28.50%**  | +5.04 п.п.  |


### Conclusion

Добавление четырёх ручных субъектов не приводит к существенному изменению средней абсолютной ошибки Greedy.

При этом относительные показатели качества меняются сильнее, особенно в хвосте распределения.

Устойчивое различие между порядками сохраняется:

- `ascending` имеет лучшее типичное качество;
- `descending` лучше контролирует наиболее плохие случаи;
- `original` используется как нейтральная контрольная конфигурация.

```
    ↓

    ↓

```

Вторая:

```

    ↓

    ↓

```

ДНР и Запорожская область получили страны, которые не были заняты в старом 85-субъектном распределении и поэтому не вызвали аналогичной цепной перестановки.

### Error impact

Дополнительная абсолютная ошибка относительно старого baseline:

```
Новые 4 субъекта:       +10095 км²
Изменение старых 5:     +19904 км²
---------------------------------
Общий прирост:          +29999 км²
```

Проверка:

```
655090 - 625091 = 29999 км²
```

Таким образом, рост общей абсолютной ошибки полностью объясняется добавлением четырёх новых субъектов и связанным с ними локальным перераспределением.

## 9. Current baseline

После восстановления полного pipeline текущим baseline считается набор из **89 субъектов**.

Для сравнения алгоритмических изменений использовать:

- одинаковый набор из 89 субъектов;
- одинаковый набор подготовленных стран;
- ограничение `country area <= subject area`;
- три порядка обработки: `original`, `ascending`, `descending`;
- 89 назначений;
- 0 нарушений ограничений.

Результаты новой серии:


| Subject order | Average absolute error | Median absolute error | Maximum absolute error | Average relative error | Median relative error | Maximum relative error |
| ------------- | ---------------------- | --------------------- | ---------------------- | ---------------------- | --------------------- | ---------------------- |
| `original`    | 7360.6 км²             | 3060 км²              | 68410 км²              | 8.34%                  | 4.17%                 | 52.15%                 |
| `ascending`   | 7360.6 км²             | **2380 км²**          | 69130 км²              | **7.99%**              | **2.41%**             | 68.74%                 |
| `descending`  | 7360.6 км²             | 4755 км²              | **43000 км²**          | 8.81%                  | 6.79%                 | **28.50%**             |


### Current interpretation

На текущем наборе данных `ascending` является предпочтительной конфигурацией, если основной критерий — типичное качество назначения.

`descending` является предпочтительной конфигурацией, если основной критерий — ограничение наиболее плохих назначений.

`original` остаётся контрольной конфигурацией.
