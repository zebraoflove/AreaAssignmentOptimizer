# HYPOTHESES

Список проверяемых гипотез проекта и результатов их экспериментальной проверки.

## Статусы

- **OPEN** — гипотеза сформулирована, но ещё не проверена.
- **SUPPORTED** — результаты эксперимента подтверждают гипотезу.
- **REJECTED** — результаты эксперимента не подтверждают гипотезу.
- **PARTIALLY SUPPORTED** — результаты подтверждают гипотезу только в части критериев.
- **DEFERRED** — проверка отложена.

---

## H-001 — Влияние ограничения площади

**Статус:** SUPPORTED

**Гипотеза:**

> Ограничение `country area <= subject area` существенно влияет на качество результата Greedy и может ухудшать итоговое распределение по сравнению с вариантом без этого ограничения.

### Вывод

Гипотеза подтверждена.

Ограничение существенно влияет на качество текущего Greedy-распределения. При этом его ухудшающее влияние на метрики не является основанием для отказа от ограничения, поскольку оно отражает предметное требование задачи.

Подробные результаты приведены в `experiments/EXPERIMENTS.md`.

## H-002 — Преимущество нисходящего порядка обработки

**Статус:** PARTIALLY SUPPORTED

**Гипотеза:**

> Обработка субъектов в порядке убывания площади улучшит качество итогового распределения Greedy.

### Вывод

Гипотеза частично подтверждена.

Нисходящий порядок улучшает показатели наиболее плохого случая, но ухудшает среднее и медианное типичное качество распределения.

Таким образом, `descending` лучше контролирует наиболее тяжёлые ошибки, но не обеспечивает лучшего общего качества.

Подробные результаты приведены в `experiments/EXPERIMENTS.md`.

## H-003 — Влияние порядка обработки субъектов

**Статус:** SUPPORTED

**Гипотеза:**

> Порядок обработки субъектов влияет на итоговое распределение Greedy.

### Вывод

Гипотеза подтверждена.

Изменение порядка обработки приводит к различиям в структуре распределения и показателях качества.

На текущем наборе из 89 субъектов:

- `original` — средняя относительная ошибка 8.34%;
- `ascending` — 7.99%;
- `descending` — 8.81%.

При этом суммарная абсолютная ошибка для всех трёх вариантов остаётся одинаковой — 655090 км².

Таким образом, порядок обработки влияет прежде всего на распределение ошибок между отдельными назначениями и на показатели типичного и максимального качества, но не на текущую суммарную абсолютную ошибку.

Подробные результаты приведены в `experiments/EXPERIMENTS.md`.

```

```

```

    ↓
```

Гипотеза подтверждена на текущем наборе данных.

Для всех трёх проверенных вариантов:

- `original`; 
- `ascending`; 
- `descending`; 

суммарная абсолютная ошибка составляет `655090 км²`.

При этом распределение ошибок между субъектами существенно различается.

**Статус:** PARTIALLY SUPPORTED

**Гипотеза:**

> Обработка субъектов в порядке возрастания площади улучшит качество итогового распределения Greedy.

### Вывод

-  средняя относительная ошибка — 7.99%;

-  максимальная относительная ошибка — 68.74%. 

Таким образом, `ascending` показывает лучшее типичное качество, но хуже контролирует крайние случаи.

## H-007 — Добавление новых субъектов вызывает локальный цепной эффект

**Гипотеза:**

> Добавление новых субъектов в задачу может вызывать цепные перестановки уже существующих назначений, поскольку новые субъекты конкурируют за страны с ранее обработанными субъектами.

Гипотеза подтверждена на переходе от старого набора из 85 субъектов к актуальному набору из 89 субъектов.

После добавления четырёх новых субъектов:

-  80 из 85 старых назначений сохранились; 
-  5 из 85 старых назначений изменились; 
-  4 новых субъекта получили назначения. 

Изменения образовали локальные цепочки перераспределения.

Основная цепочка:

```

```

```
Херсонская область
→ Solomon Islands
→ Ульяновская область
→ Equatorial Guinea
→ Рязанская область
→ Burundi
→ Московская область
→ Haiti
→ Псковская область
→ Abkhazia
```

Отдельная цепочка:

```

```

```
Луганская Народная Республика
→ Azad Kashmir
→ Белгородская область
→ Kuwait
```

Таким образом, добавление небольшого числа новых субъектов может приводить не только к появлению новых назначений, но и к локальному изменению ранее сформированного распределения.

## H-009 — Локальная жадная оптимальность не гарантирует глобального качества

**Статус:** OPEN

**Гипотеза:**

> Выбор лучшего доступного назначения на каждом шаге Greedy может приводить к неоптимальному глобальному распределению, поскольку раннее решение изменяет множество вариантов, доступных последующим субъектам.

### Мотивация

Проведённые эксперименты показывают, что:

-  изменение порядка обработки субъектов меняет конкретные назначения; 
-  изменение порядка меняет распределение ошибок между субъектами; 
-  суммарная абсолютная ошибка при этом может оставаться одинаковой; 
-  добавление новых субъектов вызывает цепные перестановки; 
-  часть существующих назначений может ухудшаться после появления новых конкурирующих субъектов. 

Эти наблюдения согласуются с предположением о локальном характере текущей жадной стратегии.

Однако текущие эксперименты сами по себе не доказывают существование существенно лучшего глобального решения.

### Следующая проверка

Гипотезу следует проверить методами, способными изменять уже сформированные назначения, например:

-  локальный обмен назначениями; 
-  локальный поиск; 
-  улучшение готового Greedy-решения; 
-  стохастические эвристические методы; 
-  точные методы оптимизации. 

Критерием проверки должно быть улучшение качества относительно зафиксированного Greedy baseline при сохранении всех предметных ограничений.

# Направления для последующей проверки

Следующие методы пока не являются проверенными гипотезами. Они рассматриваются только как возможные направления дальнейшего исследования.

## Локальная оптимизация

-  локальный обмен комбинациями; 
-  локальный поиск; 
-  улучшение готового Greedy-решения. 

## Стохастические и эвристические методы

-  simulated annealing; 
-  tabu search; 
-  генетический алгоритм. 

## Точные методы оптимизации

-  ILP / MIP; 
-  branch and bound. 

Перед реализацией конкретного метода должна быть сформулирована отдельная проверяемая гипотеза и определены критерии сравнения с текущим baseline.
