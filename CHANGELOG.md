# CHANGELOG

Все значимые изменения проекта фиксируются здесь.

## [0.2.3] — В разработке

### Pipeline modernization

- Реализовано ручное добавление субъектов РФ, отсутствующих в исходном источнике.
- Добавлены четыре дополнительных субъекта РФ.
- Исправлен pipeline подготовки субъектов: ручные субъекты проходят общий путь от `subjects_raw` до `subjects_final`.
- Исправлено дальнейшее прохождение вручную добавленных субъектов в candidate generation и алгоритмы сопоставления.
- Подтверждена обработка полного набора из 89 субъектов РФ.
- Начата централизация конфигурации предметных данных.
- Убрано дублирование предметных правил между конфигурационными модулями.
- Нормализация организуется как последовательность специализированных этапов.
- `import_adjustments.py` используется как координатор pipeline.
- Удалены устаревшие модули первоначальной архитектуры и файлы-заглушки.
- Актуализирована структура каталогов.

### Greedy re-evaluation

- Проведена повторная оценка Greedy после завершения нормализации и исправления pipeline.
- Проверены варианты порядка обработки:
  - `original`;
  - `ascending`;
  - `descending`.
- На актуальном наборе из 89 субъектов все варианты сформировали полное допустимое распределение.
- Для всех вариантов получено 89 уникальных назначений субъектов и стран.
- Нарушений ограничений не обнаружено.
- Зафиксировано одинаковое значение суммарной абсолютной ошибки для всех проверенных порядков.
- Исследовано влияние порядка обработки на распределение отдельных ошибок и показатели типичного качества.
- Результаты зафиксированы в `experiments/EXPERIMENTS.md`.

### Documentation

- Актуализирована документация состояния проекта.
- Актуализирована логическая модель данных.
- Актуализированы архитектурные решения.
- Актуализированы roadmap и список задач.
- Обновлён набор проверяемых гипотез.
- Зафиксированы результаты новой серии экспериментов.
