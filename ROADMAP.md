# ROADMAP

## 1. Project foundation — завершено

Сформирована базовая архитектура проекта, структура каталогов и конфигурация разработки.

## 2. Data infrastructure — завершено

Создана инфраструктура хранения, подключения и импорта исходных данных.

## 3. Candidate generation — завершено

Реализована генерация допустимых комбинаций государств для субъектов РФ.

## 4. Baseline algorithm — завершено

Реализован базовый жадный алгоритм `Greedy` с необходимыми ограничениями и вариантами порядка обработки субъектов.

## 5. Experiment infrastructure — завершено

Создана воспроизводимая инфраструктура запуска экспериментов, оценки результатов и сохранения отчётности.

## 6. Data normalization — завершено

Уточнены состав государств и территорий, правила территориальных корректировок, модель итоговых площадей и метаданных.

Реализовано и протестировано ручное добавление отсутствующих государств и спорных территорий. Завершена работа с `COUNTRY_METADATA` и приведены необходимые заметки к единому нейтральному формату.

## 7. Normalization architecture — текущий этап

Выделение специализированных этапов нормализации данных в независимые модули.

`import_adjustments.py` должен выступать преимущественно как координатор pipeline, а не содержать реализацию всех специализированных этапов.

Планируемые специализированные модули:

- нормализация названий;
- территориальные корректировки;
- ручное добавление отсутствующих государств/территорий;
- ручные метаданные;
- другие специализированные правила обработки данных по мере необходимости.

Модули должны иметь максимально независимый интерфейс и позволять **добавлять, отключать или заменять отдельный этап без существенной переработки остальных этапов pipeline**.

## 8. Greedy re-evaluation

Повторная оценка базового алгоритма после завершения нормализации данных.

## 9. Algorithm improvement

Исследование слабых мест `Greedy` и разработка более эффективного алгоритма сопоставления.

Конкретный подход будет определён после анализа baseline и результатов экспериментов.

## 10. Finalization

Проверка целостности данных, воспроизводимости системы и соответствия итоговой реализации спецификации.

Подготовка финального описания алгоритмов и результатов проекта.
