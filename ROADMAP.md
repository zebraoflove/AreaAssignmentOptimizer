## 7. Normalization architecture — завершено

Специализированные этапы нормализации выделены в независимые модули.

`import_adjustments.py` используется преимущественно как координатор pipeline и последовательно запускает необходимые этапы обработки.

Текущая цепочка включает:

- нормализацию названий стран;
- ручное добавление отсутствующих государств/территорий;
- территориальные корректировки;
- формирование `countries_final`;
- пересборку `candidate_sets`.

Архитектура позволяет изменять отдельные этапы без существенной переработки остальных частей pipeline.

Полный pipeline протестирован после изменений.

Контрольные результаты:

- `countries_raw`: 248;
- `subjects_raw`: 89;
- `subjects_final`: 89;
- `countries_final`: 204;
- `candidate_sets`: 89;
- `candidate_set_items`: 7798;
- `assignments`: 89.

- `original`;

Для всех вариантов:

- 89 уникальных субъектов;

## 9. Algorithm improvement — текущий этап

Исследование слабых мест `Greedy` и разработка следующего алгоритма сопоставления.

На текущем этапе необходимо:

- проанализировать распределение ошибок;
- определить причины крупных ошибок;
- изучить влияние порядка обработки субъектов;
- определить ограничения текущей жадной стратегии;
- сформулировать проверяемые гипотезы улучшения;
- выбрать следующий алгоритм сопоставления;
- провести сравнительный эксперимент с текущим Greedy baseline.

Текущий baseline для сравнений:

- 89 субъектов;
- 204 страны в `countries_final`;
- ограничение `country area <= subject area`;
- 89 candidate sets;
- Greedy;
- `original`, `ascending`, `descending`.
