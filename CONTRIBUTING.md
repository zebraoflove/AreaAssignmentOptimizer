# CONTRIBUTING

## Основные принципы разработки

1. Один источник истины — SQLite.
2. Все изменения проходят через Git.
3. Каждый законченный этап оформляется отдельным коммитом.
4. Архитектурные изменения допускаются только при наличии серьёзных оснований.
5. Каждый новый модуль должен быть максимально близок к финальной версии.
6. Производные данные не редактируются вручную.
7. Код должен быть воспроизводимым и документированным.
