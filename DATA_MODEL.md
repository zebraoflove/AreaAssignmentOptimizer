# DATA MODEL

## Назначение

Документ описывает логическую модель данных проекта и назначение основных таблиц SQLite.

SQLite является единственным источником истины для рабочих данных проекта.

Точная техническая структура базы данных определяется файлом:

```text
database/schema.sql
```

## Основные принципы

- исходные и ручные данные поступают в SQLite;
- raw-данные и подготовленные данные хранятся раздельно;
- производные данные формируются программно;
- производные данные не редактируются вручную;
- территориальные корректировки должны быть воспроизводимыми;
- учитываемая площадь суши не должна учитываться более одного раза;
- ручные добавления должны проходить общий pipeline подготовки;
- алгоритмы сопоставления работают с подготовленными данными;
- результаты экспериментов не являются частью исходных данных.

---

## Слои данных

Логический поток данных:

```
Исходные данные
      ↓
Raw-таблицы
      ↓
Нормализация и корректировки
      ↓
Подготовленные final-таблицы
      ↓
Candidate sets
      ↓
Assignments
      ↓
Analysis / Reports
```

## Субъекты РФ

### subjects_raw

Содержит исходный набор субъектов Российской Федерации, поступающий в pipeline подготовки.

Источником записей могут быть:

-  внешние данные; 
-  ручные добавления субъектов, отсутствующих в источнике. 

Основные поля:

- `id` 
- `name` 
- `type` 
- `federal_district` 
- `area_km2` 

`subjects_raw` представляет данные до формирования окончательного подготовленного набора.

---

### subjects_final

Содержит подготовленный набор субъектов РФ, используемый последующими этапами проекта.

Основные поля:

- `id` 
- `name` 
- `type` 
- `federal_district` 
- `area_km2` 

`area_km2` представляет нормализованную площадь субъекта.

Именно `subjects_final` является входным набором субъектов для:

-  генерации candidate sets; 
-  алгоритмов сопоставления; 
-  оценки результатов. 

Ручные субъекты после добавления в `subjects_raw` проходят тот же этап подготовки, что и остальные субъекты, и становятся частью `subjects_final`.

Актуальный набор содержит:

```
subjects_final: 89
```

## Государства и территории

### countries_raw

Содержит исходные данные о государствах и территориях, импортированные из внешнего источника.

Основные поля:

- `id` 
- `name` 
- `iso_alpha2` 
- `iso_alpha3` 
- `continent` 
- `area_km2` 

Таблица представляет исходные данные до применения проектных правил нормализации.

---

### territory_adjustments

Содержит территориальные корректировки, применяемые к исходным данным.

Корректировка описывает:

-  территорию; 
-  площадь; 
-  государство-источник; 
-  государство-получатель; 
-  комментарий и основание. 

Таблица используется для воспроизводимого формирования подготовленных площадей.

---

### countries_final

Содержит подготовленный набор государств и территориальных образований, используемый алгоритмами сопоставления.

Основные поля:

- `id` 
- `name` 
- `iso_alpha2` 
- `iso_alpha3` 
- `continent` 
- `area_km2` 

`area_km2` представляет площадь после применения:

-  территориальных корректировок; 
-  правил нормализации; 
-  ручных добавлений; 
-  других определённых проектом правил подготовки. 

Именно `countries_final` является входным набором государств для генерации candidate sets.

Актуальный набор содержит:

```
countries_final: 204
```

## Связи между таблицами

### Подготовка субъектов

```
исходные данные
      │
      ├── данные источника
      │
      └── ручные добавления
                │
                ↓
          subjects_raw
                │
                ↓
       нормализация субъектов
                │
                ↓
          subjects_final
```

### Подготовка государств

```
countries_raw
      │
      ├── territory_adjustments
      │
      ├── правила нормализации
      │
      └── ручные добавления
                │
                ↓
          countries_final
```

### Генерация кандидатов

```
subjects_final
      │
      └── candidate_sets
              │
              └── candidate_set_items
                         │
                         └── countries_final
```

### Формирование назначений

```
subjects_final
      │
      └── assignments
              │
              └── assignment_items
                         │
                         └── countries_final
```

## Производные данные

`subjects_final` и `countries_final` являются подготовленными производными наборами данных.

### subjects_final

Формируется из:

```
subjects_raw
      +
правила нормализации субъектов
      ↓
subjects_final
```

### countries_final

Формируется из:

```
countries_raw
      +
territory_adjustments
      +
правила нормализации
      +
ручные добавления
      ↓
countries_final
```

Подготовленные значения не должны редактироваться вручную.

---

## Candidate generation

Генератор кандидатов использует:

```
subjects_final
countries_final
```

и формирует:

```
candidate_sets
candidate_set_items
```

Этот слой отвечает за подготовку допустимых вариантов сопоставления.

Он не определяет итоговое распределение субъектов.

Актуальный набор:

```
candidate_sets:      89
candidate_set_items: 7798
```

---

## Assignment

Слой назначения использует подготовленные candidate sets и формирует:

```
assignments
assignment_items
```

Этот слой отвечает непосредственно за выбор итоговых комбинаций.

Конкретный алгоритм сопоставления определяется отдельно и не является частью логической модели данных.

Для текущего baseline `Greedy` актуальный результат составляет:

```
assignments: 89
```

---

## Analysis

Модуль анализа использует данные из:

```
assignments
assignment_items
countries_final
subjects_final
```

и формирует производные показатели качества распределения.

Результаты анализа не изменяют основную модель данных.

---

## Эксперименты и экспорт

Эксперименты выполняются поверх подготовленных данных SQLite.

Результаты экспериментов не являются отдельным источником исходных данных.

Текстовые результаты хранятся в:

```
experiments/
```

Экспортируемые результаты хранятся в:

```
exports/experiments/
```

## Актуальный объём данных

После завершения нормализации и включения ручных субъектов:

```
countries_final:       204
subjects_final:         89
candidate_sets:         89
candidate_set_items:  7798
assignments:            89
```

Эти значения описывают текущий подготовленный набор и текущий baseline-результат, а не являются постоянными ограничениями схемы.
