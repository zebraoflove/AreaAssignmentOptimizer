# DATA MODEL

## Назначение

Документ описывает модель данных проекта и является единственным источником информации о структуре базы данных.

---

## Основные принципы

- SQLite является единственным источником истины.
- CSV используются только для импорта исходных данных и экспорта результатов.
- Каждый квадратный километр суши должен учитываться ровно один раз.
- Производные данные не редактируются вручную.

---

## Основные таблицы

### subjects

Содержит субъекты Российской Федерации.

Основные поля:

- id
- name
- type
- federal_district
- area_km2

---

### countries

Содержит государства и учитываемые частично признанные государства до территориальных корректировок.

Основные поля:

- id
- name
- continent
- iso
- status
- area_raw_km2

---

### territory_adjustments

Описывает все изменения площадей, необходимые для исключения двойного учёта территорий.

Каждая запись содержит:

- какую территорию учитывать;
- у какого государства вычесть площадь;
- какому государству добавить площадь;
- площадь изменения;
- комментарий.

---

### candidate_sets

Хранит найденные комбинации стран для каждого субъекта.

---

### candidate_items

Связывает комбинацию со входящими в неё странами.

---

### assignments

Хранит итоговое распределение комбинаций по субъектам РФ.

---

### assignment_items

Связывает итоговое распределение с конкретными странами.

---

## Представления (VIEW)

Производные данные (например, итоговые площади стран после корректировок) рекомендуется реализовывать через VIEW, а не хранить отдельными таблицами.
